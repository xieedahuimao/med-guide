# 健康用药小助手（临床用药指导 · 面向普通人）

一个**移动端优先**的小网站，用来给没有医学背景的成年人，按“部位 → 症状 → 细节”一步步选择，最后给出：
- 这个情况大概**严重不严重、要不要去医院、去大医院还是小医院**（大医院＝三级甲等）；
- 可以参考的**常见市售药（OTC）**及用法用量、以及**“别用的情况”**；
- 药物的**相互作用与错开用法**（冲突的药会自动避开）；
- 女性 + 腹部时，**宫外孕等生殖系统急症**的重要提醒；
- 最后还能**选择省份**，看看当地擅长这个病的**三甲医院**（参考）。

> ⚠️ 健康声明：本工具仅作科普参考，**不能替代医生诊断**。用药请以药品说明和医师/药师意见为准。出现紧急情况立即拨打 120。

## 目录结构

```
index.html          入口页面
css/style.css       样式
js/data.js          知识库（部位、症状、药物、禁忌、严重度）
js/engine.js        安全引擎（药物匹配 + 相互作用 + 就医红线）
js/hospitals.js     医院参考库（省份 → 擅长科室）
js/app.js           交互逻辑
```

## 本地预览（电脑上先看一下）

直接双击打开 `index.html` 就能用。也可以起一个本地静态服务器：

```bash
npx serve .
# 或
python -m http.server 8080
```

浏览器打开 `http://localhost:8080` 即可。

## 上传到 Gitee 并开启 Gitee Pages（手机即可访问）

这个网站是**纯静态**的，不需要任何构建，gitee.com 就能直接托管。

1. **注册 / 登录**：打开 gitee.com 登录账号。注意：**Gitee Pages 需要完成实名认证**才能使用。

2. **新建仓库**：右上角 `+` → `新建仓库`，起个名字（如 `med-guide`），选 **公开**，点 `创建`。

3. **上传文件**：进入仓库 → 点 `上传文件`（或 `添加文件`）→ 把下面这些**放到仓库根目录**：
   - `index.html`
   - `css`（整个文件夹）
   - `js`（整个文件夹）

   然后点 `提交`。

4. **开启 Pages**：仓库页 → 顶部 `服务` → `Gitee Pages` →
   - 分支选你的默认分支（一般是 **master**）
   - 部署目录选 **根目录**
   - 点 `启动`

5. **等待 1~2 分钟**，会生成网址：
   ```
   https://你的用户名.gitee.io/仓库名/
   ```
   用手机浏览器打开这个链接就能用了。

> 提示：
> - 因为网址带 `/仓库名/` 子路径，本项目所有资源都用了**相对路径**（`css/...`、`js/...`），所以能正常显示，**不要改成绝对路径**。
> - 每次修改后，需要到 `服务 → Gitee Pages` 点一次 **`更新`**，才会重新部署。
> - 免费版 Gitee Pages 不支持自定义域名（绑定自己的域名需付费版）。
